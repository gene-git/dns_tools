Dependencies
============

**Run Time** :

* python (3.14 or later)
* ldns
* lockmgr
* pyconcurrent

**Building Package**:

* git
* meson
* meson-python
* rsync

.. _manual_build:

Build Manually
==============

To build it manually, clone the repo and do:

.. code-block:: bash

    ./scripts/do-build
    ./scripts/do-install <destination-directory>
