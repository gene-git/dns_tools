2. Appendix¶

2.1. Dependencies¶

Run Time :

  • python (3.14 or later)

  • ldns

  • lockmgr

  • pyconcurrent

Building Package:

  • git

  • meson

  • meson-python

  • rsync

2.2. Build Manually¶

To build it manually, clone the repo and do:

./scripts/do-build
./scripts/do-install <destination-directory>
